# Сайт-портфолио: Zhailoobek Tukubaev — GIS & Geospatial Expert

Многоязычный (EN / RU / KG) сайт-портфолио с интерактивной ГИС-лабораторией и защищённой админ-панелью.

**Технологии:** Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS · Framer Motion · Leaflet · @tmcw/togeojson. Всё бесплатное, без внешних платных сервисов.

## 2. Установка на Windows 11

1. Установите **Node.js 20 LTS или новее**: https://nodejs.org (кнопка LTS) или в PowerShell:

   ```powershell
   winget install OpenJS.NodeJS.LTS
   ```

   Закройте и снова откройте терминал, проверьте: `node -v`.

2. Откройте папку проекта в терминале и установите зависимости:

   ```powershell
   npm install
   ```

3. Создайте файл настроек: скопируйте `.env.example` в `.env.local`:

   ```powershell
   Copy-Item .env.example .env.local
   ```

4. Задайте пароль администратора (минимум 10 символов) — команда выведет готовую строку:

   ```powershell
   npm run hash-password -- "ВашНадёжныйПароль"
   ```

   Вставьте строку `ADMIN_PASSWORD_HASH=...` в `.env.local`.

5. Сгенерируйте секрет для сессий и вставьте его в `AUTH_SECRET=` в `.env.local`:

   ```powershell
   node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
   ```

6. Запустите сайт в режиме разработки:

   ```powershell
   npm run dev
   ```

   Откройте http://localhost:3000 — сайт, http://localhost:3000/admin — админ-панель (логин `admin`, если не меняли `ADMIN_USERNAME`).

> Перед запуском автоматически создаётся `public/geo/kyrgyzstan.geojson` (граница КР из открытого набора Natural Earth). Если этого файла нет, карты работают, просто без контура страны.

## 3. Первое, что нужно сделать в админ-панели

1. **Сертификаты → проверить и одобрить каждый скан.** Сканы из PDF уже подготовлены (страницы, лежавшие боком, повёрнуты), но до одобрения посетители видят только описание без изображения. Откройте каждый сертификат, проверьте скан и отметьте «Изображение проверено и одобрено для публикации», затем «Сохранить».
2. **Образование → диплом.** Подготовлена публичная копия только титульного разворота: номер диплома, регистрационный номер и QR-коды закрыты. Приложение к диплому (с датой рождения и оценками) не используется. Проверьте копию и одобрите её так же.
3. **Контакты** — добавьте телефон, WhatsApp, Telegram, LinkedIn, GitHub. Пустые поля на сайте не показываются.
4. **Проекты / Портфолио** — загрузите карты, ортофотопланы, фото полевых работ, скриншоты (JPG/PNG/WEBP/PDF до 15 МБ). Не загружайте служебные или ограниченные геоданные.
5. **Тексты интерфейса** — при желании уточните кыргызский перевод меню и кнопок.

Каждое сохранение создаёт резервную копию в `data/backups/` (последние 30).

## 4. Где хранятся данные

| Путь | Содержимое |
|---|---|
| `data/content.json` | Весь текст сайта на трёх языках (редактируется из админки) |
| `data/documents/` | Сканы сертификатов и копия диплома. Отдаются через `/api/media/documents/…` **только после одобрения** |
| `data/uploads/` | Файлы, загруженные в админке |
| `data/messages.json` | Сообщения из формы обратной связи (видны в админке → «Сообщения») |
| `src/lib/i18n/*.ts` | Стандартные тексты интерфейса EN / RU / KG |

**PostgreSQL + PostGIS не требуется**: сайт не выполняет пространственных запросов на сервере, а ГИС-лаборатория обрабатывает файлы прямо в браузере. Если позже понадобится публичный каталог геоданных с запросами, слой хранения легко заменить: все чтения/записи собраны в `src/lib/content.ts`.

## 5. Публикация в интернете

Админ-панель записывает файлы на диск, поэтому нужен сервер с постоянным диском.

### Вариант А — VPS (рекомендуется; Ubuntu, любой хостинг)

```bash
git clone <ваш-репозиторий> portfolio && cd portfolio
npm ci
cp .env.example .env.local   # заполните NEXT_PUBLIC_SITE_URL=https://ваш-домен, ADMIN_PASSWORD_HASH, AUTH_SECRET
npm run build
npm install -g pm2
pm2 start npm --name portfolio -- start
pm2 save && pm2 startup
```

Nginx как обратный прокси на `localhost:3000` (с заголовком `proxy_set_header X-Forwarded-Proto $scheme;`) и бесплатный HTTPS через Let’s Encrypt (`certbot --nginx`). Входите в админку только по HTTPS.

### Вариант Б — Render / Railway / Fly.io

Тип сервиса Node, сборка `npm ci && npm run build`, запуск `npm start`. Подключите постоянный диск (volume) к папке `data/`, иначе правки из админки пропадут при перезапуске.

### Текущая публикация — Vercel

Сайт опубликован на https://jailoobek.xyz (домен куплен в Vercel, DNS — Vercel DNS; `www.jailoobek.xyz` и `tukubaev-gis-portfolio.vercel.app` перенаправляют на основной домен) и подключён к репозиторию GitHub: каждый `git push` в ветку `main` автоматически пересобирает и публикует сайт (1–2 минуты).

Ограничения Vercel (файловая система только для чтения):
- админка на Vercel отключена (не заданы `ADMIN_PASSWORD_HASH` и `AUTH_SECRET`) — содержимое редактируйте в локальной админке (`npm run dev` → http://localhost:3000/admin), затем `git add -A`, `git commit`, `git push`;
- форма обратной связи не сохраняет сообщения — посетители видят email для связи;
- сканы сертификатов (`data/documents/`) не входят в репозиторий и на Vercel не показываются.

В Vercel задана переменная `NEXT_PUBLIC_SITE_URL=https://jailoobek.xyz` — от неё строятся sitemap, canonical и hreflang. При смене домена поменяйте её в Vercel → Settings → Environment Variables и пересоберите сайт. Домен продлевается в Vercel ежегодно (следующее продление — 26.10.2027).

### После публикации

- Укажите реальный адрес в `NEXT_PUBLIC_SITE_URL` и пересоберите — от него строятся `sitemap.xml`, canonical и hreflang.
- Добавьте сайт в Google Search Console и отправьте `https://ваш-домен/sitemap.xml`.

## 6. Безопасность

- Пароль хранится только как хеш scrypt; сессия — подписанная HMAC cookie (httpOnly, SameSite=Strict, Secure при работе по HTTPS, 8 часов).
- Защита `/admin` и `/api/admin/*` в middleware и повторная проверка в каждом обработчике; ограничение попыток входа (8 за 15 минут); проверка Origin.
- Загрузка: белый список расширений, проверка сигнатуры файла, лимит 15 МБ, случайные имена; SVG/HTML запрещены.
- Форма обратной связи: honeypot и лимит 5 сообщений за 10 минут с одного адреса.
- На сайте нет паспортных данных, даты рождения, домашнего адреса и номеров документов.
